# yt2aep — 動画を見て、編集できるAEプロジェクトを作る道具

After Effectsのチュートリアル動画をAIと読み解き、標準エフェクトで組み直すためのツール集です。AIが映像と数値を確認し、JSXを書いてAEで実行します。自動で完全一致する変換ソフトではありません。

1. このフォルダを、ローカルファイルとコマンドを扱えるAIに開かせます。
2. 下の文と、参考にする動画のURLを渡します。
3. AIと準備を確認してから、AEで作成・比較します。

> AGENTS.mdを読んで、この動画を編集可能なAEプロジェクトにしてください。開いている別のプロジェクトには触れず、読めない値と代用した部分を記録してください。動画URL：ここに貼る

準備は **Python 3（3.9以上）・Pillow・ffmpeg・yt-dlp・After Effects**。導入と実行例は [AGENTS.md](AGENTS.md) にあります。MacとWindows向けです。

- `tools/`：動画からの比較シート作成、AEへの実行指示
- `jsx/`：共通部品、プレビュー・書き出し
- `jsx/examples/build_glitch.jsx`：標準エフェクトのグリッチテキスト例
- `ref/fx_catalog.txt`：エフェクトとプロパティのmatchName

例は `output/glitch/` にAEPとPNGを保存します。ヌル「コントロール」の「グリッチの強さ」「光の強さ」「イン・アウトの速さ」を調整できます。フォントが無ければ別のフォントに置き換わり、見た目が変わります。

自分のチャンネル以外の動画は利用条件を守り、配布素材・プロジェクトの使い方も確認してください。
